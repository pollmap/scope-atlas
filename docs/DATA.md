## DART 보강

[기업개황](https://dart.fss.or.kr/dsae001/main.do)의 [공개 엑셀](https://dart.fss.or.kr/dsae001/downloadExcel.do) 119,391행을 2026-09-20에 조회해 보강 참조로 사용했습니다. 원본 전체는 저장소에 포함하지 않습니다. 기업별 마지막 신고일과 현재 영업 지속 여부를 보장하지 않습니다.

| 기존 명부의 연결 키 | DART에서 대조할 키 |
|---|---|
| 기업집단 법인등록번호 | 법인등록번호 |
| 중견기업 사업자등록번호 | 사업자등록번호 |
| KIND 종목코드 | 종목코드 |

각 키가 유일하게 일치하고 DART 법인등록번호도 유효한 형식이며 중복되지 않을 때만 법인 키를 부여합니다. 이는 번호 체크섬이나 법적 자격 인증을 수행한다는 뜻은 아닙니다. 원자료의 법인번호로 만든 해시를 연결 키로 사용하고, 기존 출처 ID·이름·기준일은 변경하지 않습니다. 일부 기존 출처 ID는 공식 법인 식별자를 포함합니다.

| 대조 상태 | 출처 항목 |
|---|---:|
| 식별자 일치 | 9,784 |
| 식별자 중복으로 보류 | 11 |
| 일치 참조 미확보 | 331 |
| 참조 법인번호 불충분 | 22 |
| 대조용 식별자 미확보 | 7,173 |

확인된 부분에는 8,188개 법인 키가 있으며, 그중 여러 출처에 나타난 1,484개 법인에 3,064행이 연결됩니다. 이를 전체 고유 기업 수로 환산하지 않습니다. 동일 명부 안의 복수 기록도 원래 ID로 유지합니다.

이름 후보는 법인 표기·공백 제거 후의 명칭 일치입니다. 사실을 자동 전파하지 않으며, 양쪽에 확인된 법인 키가 있고 서로 다르면 후보에서 제외합니다. 공식 업종은 원문으로 보존하고 별도의 탐색 산업으로 재분류합니다.

## 공개 파일

| 파일 | 내용 |
|---|---|
| `catalog.json` | 출처 ID, 명칭, 업종·사업, 지역, 홈페이지, 분류 근거, 확인된 법인 연결 |
| `evidence.json` | 152개 중앙 기관에 연결된 153건의 과거 공식 공고 메타데이터 |
| `manifest.json` | 기준일, 출처별 행 수, 집계 단위, 보강 전후 수치, 해석 제한 |

비어 있는 값은 ‘없음’이 아닌 ‘미확인/미기재’로 표시합니다. 원자료의 소재지·관할 지역은 실제 입사 후 근무지와 다릅니다. DART 업종만 보강한 행에는 ‘공시 업종’이라고 표시하고, KIND 제품 설명을 가져온 경우 그 출처를 별도로 남깁니다.

## 재현 가능한 범위

저장소의 공개 스냅샷으로 웹앱 실행, 빌드, UI 계산, 모든 단위검사를 재현할 수 있습니다. 내부 수집 원본은 포함하지 않으므로 `npm run data:build`가 깨끗한 클론만으로 완료되지는 않습니다.

전체 재생성은 `scripts/build-data.py`와 `scripts/discovery.py`에서 요구하는 상위 작업 폴더의 `work/normalized`·공고 원본을 별도로 확보해야 합니다. DART 엑셀은 내부 `qa/scope/dart-company-download.bin`에서 `scripts/prepare-company-reference.py`로 정규화합니다. `scripts/entity_enrichment.py`가 식별자를 대조합니다. 스냅샷 날짜·파일명·출처를 함께 갱신하고 새 검수 결과를 남겨야 합니다.

업종 분류가 어려운 행을 삭제하거나 결측을 0으로 채우지 않습니다. 출처별 행 수·기존 저장 ID·법인 충돌·차트 집계와 목록의 일치를 확인한 뒤 공개 파일을 교체합니다.

## 이용 범위

장문 제휴 콘텐츠, 개인 합격사례, 대표자·전화·팩스 원본, 인증정보는 수록하지 않습니다. 공식 원문에 대한 권리는 해당 제공처에 있으며, 공개 링크가 있다는 이유만으로 원문 전체 재배포를 허용하는 것은 아닙니다.
